# Phase Update Template

Copy this structure into the relevant phase note after each milestone:

## Status

Completed, blocked, or in progress.

## Commands

List the exact commands used.

## Inputs and Outputs

Record source paths, output paths, row counts, part counts, and file sizes where relevant.

## Evidence

Record measured data facts, validation results, and test results.

## Decisions

Record schema, filtering, scoring, or identity decisions made from the evidence.

## Limitations

Record known gaps and the next concrete follow-up.
